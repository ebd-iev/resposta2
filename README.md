# EBD Digital: Hermenêutica e Interpretação Bíblica

Apresentação interativa, responsiva e otimizada para dispositivos móveis, desenvolvida para ser utilizada na **Escola Bíblica Dominical (EBD) - Classe de Doutrina**.

O tema central é: *"A Bíblia tem muitas interpretações ou um único significado?"*, abordando princípios de hermenêutica gramático-histórica e a regra de fé.

## 🚀 Funcionalidades
- **Arquivo Único:** Todo o código (HTML, CSS e JavaScript) está contido em um único arquivo, facilitando o compartilhamento e a hospedagem (ex: GitHub Pages).
- **Mobile-First:** Design otimizado para telas de celular (proporção 9:16), com suporte a `safe-area-inset` para iPhones com notch.
- **Navegação Intuitiva:** Avance e volte os slides tocando nas laterais da tela ou usando as setas do teclado.
- **Barra de Progresso:** Indicador visual no topo para saber o avanço da apresentação.
- **Design de Alto Contraste:** Gradientes escuros sobre as imagens de fundo para garantir a legibilidade do texto em qualquer dispositivo.

## 🛠️ Tecnologias Utilizadas
- HTML5 Semântico
- CSS3 (Flexbox, Variáveis CSS, Backdrop-filter, Clamp para tipografia responsiva)
- JavaScript Vanilla (Sem dependências ou frameworks)

## 📖 Como Usar
1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` diretamente em qualquer navegador moderno (Chrome, Safari, Firefox).
3. Para testar a experiência mobile no computador, use o "Modo de Dispositivo" (F12) do navegador.
